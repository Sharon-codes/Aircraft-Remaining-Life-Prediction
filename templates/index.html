About This Project

Leveraging NASA's C-MAPSS dataset for predictive maintenance

NASA C-MAPSS Dataset

This project utilizes NASA's Commercial Modular Aero-Propulsion System Simulation (C-MAPSS) dataset to train machine learning models for predicting the Remaining Useful Life of turbofan engines.

The model analyzes 14 key sensor readings including temperature, pressure, and speed measurements from various engine components to estimate how many operational cycles remain before maintenance is required.
